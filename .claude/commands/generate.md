SNSポスト（Threads）を生成してスプレッドシート用に変換します。

---

## ⚠️ 絶対に守るルール

### ポスト生成は必ずClaude自身が行うこと
- **Task tool（サブエージェント）を使ってポスト生成をしてはいけない**
- サブエージェントはルールを知らないため、短くて型のない粗悪なポストを生成する

### 生成前に必ず読み込むファイル
- `postgen/skills/prompt.md` ← 生成ルール・出力フォーマット・日本語ルール
- `postgen/skills/knowledge.txt` ← 型01〜型21（投稿構造パターン21種）
- `postgen/skills/themes.txt` ← ペルソナ・頻出ワード100選・テーマ120選・**伸びない投稿パターン（禁止リスト）**
- ルートの `CLAUDE.md` ← キャラクター設定（口調・禁止ワード）

### 文字数基準（必須）
- **単ツイート：200〜500字**
- **ツリー：1ツイートあたり200〜500字**
- これを下回るポストはNGとして書き直すこと

### 型の使い方（必須）
- 10本の中で同じ型を2回使わない
- 型01〜型21の構造を実際に適用して書く
- 形式A（単ツイート）6〜7本 + 形式B（ツリー）3〜4本
- ※型04の「アフィリンク配置」・型07の「note誘導」は使わない。CTAは「フォロー保存」か「DM予約」に置き換える

### 頻出ワード（必ず各投稿に2〜3個入れる）
カテゴリ1（★★★名乗り・定番）: 札幌市西区で自律神経を見る仕事をしてますが / 今日来た〇〇の人 / 〇年ものの鬱 / 主訴 / まず体のチェック / ①②③④ / こういう話が好きな方フォロー保存お願いいたします
カテゴリ2（★★★施術・見立て）: 痛さが10→6→3 / ①②③④消失 / 筋力テスト / 眼球チェック / 足首の固さを取る / 脳血流 / 根本原因 / 深掘りする / 見立て / トラウマ除去
※カテゴリ6（スピ・霊障系）は1投稿1回まで

### 禁止リスト（themes.txt末尾「伸びない投稿パターン」）
- 患者の顔が見えない一般論・解説の単体投稿
- 日常つぶやき・業務連絡
- 数値変化・具体例のない断片知識
- note誘導・アフィリンク
- 「治る」「治療」の断言、ぼかし表現

### 出力フォーマット（厳守）
```
[ポスト本文]
（200〜500字のポスト本文）
==========
```
ツリーの場合：
```
[ポスト本文]
■1ツイート目
（200〜500字）
■2ツイート目
（200〜500字）
==========
```

## 実行手順

1. 上記4ファイルを読み込む
2. `postgen/generated/` の既存ファイルの最大連番を確認する
3. ルールに従い10件のポストを生成する（前置き・説明なし、フォーマット厳守）
4. `postgen/generated/generated_posts_XXXX.txt` に保存する（XXXXは連番）
5. `cd postgen && python convert_tsv.py generated/generated_posts_XXXX.txt` を実行（TSV生成。--clipboard と paste_to_sheet.py はローカルPCでのみ実行可能）

## 引数

- `$ARGUMENTS` に日付が指定されている場合、`--start-date` オプションで渡す
- 日付指定がなければ今日の日付を使う

今すぐ実行してください。途中で確認を挟まず、ノンストップで完了まで進めてください。
