## 4. 品質がブレる原因（洗い出し）

1. **文字数の二重基準**：150〜250字（ルート・generate.md冒頭）vs 200〜500字（prompt.md・generate.md出力フォーマット欄・postgen/CLAUDE.md Step1）。長さが安定しない直接原因
2. **別人格プロンプトが「必読」に入っている**：generate.mdが読み込みを義務付ける4ファイルのうち、prompt.mdとknowledge.txtの2つが別アカウント仕様
3. **抜粋コピー方式の宿命**：6月中旬以降にルートへ追加された口調ルール（だ。止め禁止・「彼女」→「この人」・——禁止・証言調の生々しいセリフ・「これ、〇〇じゃない。」連発禁止・「私」一人称）がコマンド側に未反映。どのファイルを読んだかで出力人格が変わる
4. **スピ系の矛盾**：全面禁止（ルート）vs 1投稿1回OK（generate.md・themes.txt）
5. **CTA文言の揺れ**：「DMで聞いてみて」（themes.txt）vs「気になる人は、DMをくれ」（ルート・実運用）
6. **扱わないテーマの残存**：themes.txtターゲット像に「めまい」が残っている（ルートは耳鳴り・めまい・更年期・気圧を除外済み）
7. **TSV手順が文書化されていない**：番号続き・日付・時刻・間隔指定はconvert_tsv.py未対応のため毎回ワンショットPythonを手書き。手順が属人化しておりミスの温床
8. **修正サイクルが暗黙知**：修正→drafts同期→TSV/HTML再生成→コミットのループはどこにも書かれていない
9. **口頭で確立したが未文書化のルール**：DM相談・見立て3つ型／会話調と証言調の使い分け／「良くならない方が困る層を狙う」方針／責めずに味方するリフレーム——knowledge/insights に一部あるが生成ルールとしては未収載

## 5. 再設計：3層構造（Single Source of Truth）

```
層1【人格・ルール】 ルート CLAUDE.md ただ1つ
   └ 文体・禁止・CTA・文字数・型・KPI・扱わないテーマ
     ※コマンド/スキルはここを「参照」する。コピーしない

層2【ネタ・データ】 knowledge/ に一本化
   ├ episodes/   施術エピソード（使用済みフラグ運用）
   ├ insights/   見立て軸・因果関係ストック
   ├ buzz/       勝ちポスト分析
   ├ themes/     参考アカウント分析（4本、ここが正）
   └ 禁止リスト（themes.txt末尾から独立ファイル化）＋頻出ワード

層3【実行・工具】 postgen/ ＋ .claude/commands/
   ├ convert_tsv.py（要拡張：--start-num --start-minute --interval --no-random）
   ├ tsv_preview.py
   └ コマンド＝手順だけを書く。ルールは層1参照
```

**convert_tsv.py 拡張提案**（毎回のワンショットPythonを廃止するため）：
`--start-num 118 --start-date 2026-07-02 --start-hour 5 --start-minute 5 --interval 86 --no-links` の一発指定で現行の手作業と同じTSVを出せるようにする。

## 6. 再設計後のSkill一覧（用途別）

### /generate — 1バッチ10本生成【改訂】
- **役割**：拓郎ペルソナで10本生成し、drafts保存・TSV/HTML生成まで
- **使用場面**：「新しい投稿お願い」「10個作って」
- **実行手順**：
  1. ルートCLAUDE.md（ルールの唯一の正）を読む
  2. knowledge/episodes（`使用済み: no` 優先）・insights・buzz・禁止リストを読む
  3. 型の割り当てを決めて10本生成（エピソード型を1本目に。同じ型は2回まで使わない。1本目安150〜250字、深掘り2〜3本は500字上限）
  4. `postgen/generated/generated_posts_XXXX.txt`（連番）に保存
  5. `posts/drafts/YYYY-MM-DD_テーマ.md` にコピー
  6. TSV＋HTMLプレビュー生成 → HTMLをユーザーに送付
  7. コミット・プッシュ
- **出力形式**：`[ポスト本文]`〜`==========`（ツリーは`■Nツイート目`）＋チャットに10本の内訳サマリー
- **使う型（型01〜21を置換する実績リスト）**：①施術エピソード型（最強）②DM相談・見立て3つ型③列挙・対比型④共感型（証言調「」フック）⑤逆説型⑥自分ごと化型⑦知識・解説型（検査に映らない等）⑧希望の締め型

### /batch — 複数日分まとめて生成【改訂】
- **役割**：Nバッチ連続生成＋日内分散TSV
- **使用場面**：「3日分作って」
- **実行手順**：/generateをN回（ルールは/generate参照の1行のみ）→ 全ファイルまとめて `--per-day 10` でTSV化
- **出力形式**：/generateと同じ＋日別スケジュール表

### /revise — 修正反映サイクル【新設】
- **役割**：番号指定の修正（「3は〜にして」「6は差し替え」）を受けてバッチを更新
- **使用場面**：生成後のフィードバック対応（現在は暗黙運用。これを明文化）
- **実行手順**：
  1. 該当generated_posts_XXXX.txtをEdit
  2. 修正時のルール再チェック（だ。止め／——／否定→断定の連発／「彼女」／文字数）
  3. drafts へ `cp` 同期
  4. TSV・HTML再生成 → HTML送付
  5. 発行済みseq付きTSVがあればそれも再生成
  6. コミット・プッシュ
- **出力形式**：更新版HTML＋変更点の箇条書き

### /tsv — 貼り付け用TSV発行【新設】
- **役割**：番号・日付・時刻・間隔を指定してシート貼り付け用TSVを出す
- **使用場面**：「tsvに、番号は続きから、7/2、5:05、86分おき」
- **実行手順**：
  1. 前回の最終番号を `generated/*_seqNNN.tsv` から確認（例：117の次は118）
  2. convert_tsv.py（拡張後）で一発生成。除外投稿があれば指定を受ける
  3. `_seqNNN.tsv`＋確認用HTMLを生成し両方送付
  4. 早朝5〜9時にかかる場合は一言注意を添える（作りはする）
  5. コミット・プッシュ
- **出力形式**：`.tsv`（A列番号/本文/日付/時/分、改行は\r、リンク行なし）＋番号×日時の一覧表

### /log-episode — 施術メモ登録【新設・任意】
- **役割**：施術後の雑メモを `knowledge/episodes/` にテンプレ形式で追記
- **使用場面**：「今日来た人の話、メモっといて」
- **実行手順**：_TEMPLATE.mdの形式に整形→保存（`使用済み: no`）→コミット
- **出力形式**：保存先パスの報告のみ

### /menu — 【削除】
実運用で不使用。postgen/CLAUDE.mdのメニュー節とセットで廃止。
