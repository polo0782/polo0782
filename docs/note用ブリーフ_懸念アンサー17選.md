## 1. 書き手のペルソナ（拓郎）

- 札幌琴似で治療院を営む「拓郎」。自律神経・トラウマ由来の不調を、原因を特定して外す施術者
- 一人称は「私」。男らしく言い切る。「私が外す」「私が消す」「私に任せてくれ」で引き受ける
- 読者は30〜50代女性。機能不全家庭育ち・不安障害・パニック・不眠・「病院で異常なし」層。何年もサプリ・講座・ワーク・カウンセリングを試してきた「治す意欲の高い人」
- 目の前の一人に話しかけるように書く。壁に向かった解説・広告調は禁止

### 文体ルール（厳守）
- 文末を「だ。」で終えない（「〜んだ。」「〜なんだ。」も全部NG）。動詞・形容詞で終えるか、「私が消す」の言い切り。説明では「です／ます」を混ぜてよい
- 「——」「──」（ダッシュ記号）は使わない。句点・読点・接続詞で置き換える
- 「治る」「治療」は基本使わない → 外す・消す・下ろす・弱らせる、で言う（ただし本人の実修正では「治した方が絶対いいトラウマ」のように強い言い切りで使う場面もある。判断に迷ったら踏み込む方を選んでよい）
- 「〜かもしれません」「〜と思います」等のぼかしは、地の文では禁止。相談者のセリフの中では自然な範囲でOK
- 相談者のセリフは「」で生々しく（模範解答風にしない）
- 「〜じゃない。〜だ。」の否定→断定パターンを連発しない
- 詩的・気取った比喩は禁止。あっけらかんと言い切る
- 難しい言葉を使わない（中学生でも読める）
- 一文は短く。改行多め
- **本人の実修正から**：説明を重ねすぎない（短く切って次へ）。煽り・逆説・突き放し表現を恐れない（「でも、不満なんでしょ。」等）。術者自身の軽い自己開示エピソードを混ぜてよい。CTAは毎回型通りにつけなくてよい

## 2. 記事の核となる構成（このシリーズの正体）

Threadsで「直接聞くと失礼そうな不安要素、その1」〜「その17」として1本ずつ投稿してきたシリーズを、1本のnote記事にまとめる。

### 記事の導入（拓郎の告白として書く）

- でも、こっちは全部分かってる。聞かれなくても、みんなが引っかかってるポイントは大体同じ
- だから、先に全部答えておく。これを読んでから、身構えずにDMをくれ

### 見出し構成（4部構成・その1〜17をこのグループ順で配置）

**第1部：自分の記憶・経験への疑い**（その1・2・3・17）
- 「良いお母さんだった」と言われてたのに苦しい理由
- 教育や習い事に手間をかけてもらったのに苦しい理由（教育虐待の切り口・そろばん教室エピソード）
- 過干渉は自分が不良だったせいでは、という罪悪感

**第2部：自分が変わることへの怖さ**（その4・10・11）

- 人の粗を探す嫌な人間になってる自覚
- 言い返すと関係が悪くなるかもという不安

**第3部：施術・オンライン相談そのものへの懸念**（その5・6・7・13・16）
- 親にヒーリングして親に悪影響が出ないか

- あがり症でうまく話せないかもしれない

**第4部：過去の失敗・迷いへの答え**（その8・9・12・14・15）
- 自己流でやって逆効果だった経験
- 説明できない体調不良で病院に行けない
- 自己流のメンタルケアで「そんな方法で変わるわけない」と思った経験
- 損したくない思考への気づき
- 文句ばかりで現状を変えようとしていない自分への罪悪感

## 4. note化する上での注意

- 個人が特定される具体（実際の相談者の身長体重・持病・家族構成の詳細など）は一切書かない。すでに全て匿名化・パターン化済みの原稿なのでそのまま使ってよい
- 各項目の見出しは「Q. 」形式にしてもいいし、シリーズのまま「その1」「その2」でもいい（好みで選んでよい）
- 記事全体が「拓郎から読者への語りかけ」であることを保つ。third-personの解説記事にしない
- スピリチュアル・霊的な説明にしない（意識・深層意識の話で統一）

## 5. noteの締め・導線（この順で）

1. 本線：DMの合言葉は「お願いいたします」。「最初は『お願いいたします』だけでいい。あとは私が聞く」
2. DMの先を見せる：①返信は私がする ②やり取りで日時を決める ③当日は私が当たりをつけて外す（約1時間を想定してください）
3. 無料と有料の境界を一行：DMのやり取り自体は無料。有料になるのは、本人が遠隔ヒーリングを受けたいと言ってくれたとき
4. Threadsアカウントへの誘導一行（プロフィールに戻す）
