# 日本語ルール抜粋（読点・改行・助詞）

旧 `postgen/skills/prompt.md` から日本語の機構ルールだけを抽出したもの。
ペルソナ・口調・禁止ワード・CTA・文字数の正はルート `CLAUDE.md`。矛盾したらCLAUDE.mdに従う。

## 句読点・助詞（PARTICLE_RULES）

① 句点は文末のみ。文中の区切りは読点か助詞で処理する
② 読点は1文あたり1〜2個。箇条書きの項目内のみ0個を許容する
③ 1文が全角45文字を超えるか、従属節が3つ以上になったら句点で文を分ける
④ 文を分割するときは「が／で／けど／なら／ので」等の接続助詞で流れを保つ。冗長な「の／こと」は削る
⑤ 感情が高まる箇所は句点で切らず、助詞＋読点でリズムを畳みかける
　例：「つらかった、悔しかった、誰にも言えなかった。」→「つらくて、悔しくて、誰にも言えなかった。」

## 改行・体裁（7つのルール）

① 改行は「話題の切り替わり」で入れる。1〜3文のまとまりを作る。1文ごとの改行は多すぎ、改行ゼロは読みにくい
② 体言止めは締めの1回まで。途中で多用すると文が死ぬ。動詞で着地させる
③ かぎ括弧・強調記号は地の文では1投稿2個まで（患者のセリフ引用「」は除く）
④ 「〜、は〜」のような助詞の連続構造は作り直す（「休めば良くなる、は嘘」→「休めば良くなるのは嘘」）
⑤ 読点より助詞で文をつなぐ。読点を打ちたくなったら、まず助詞（は・が・を・で・に・の）で代替できないか考える。読点は助詞で解決できない場所にだけ打つ
⑥ 長文は45字で句点分割（PARTICLE_RULES③）。分けた後、話題が変わるなら改行してよい
⑦ 感情の高まりは助詞＋読点で畳みかける（PARTICLE_RULES⑤）

## その他のNGパターン

- 「〜のを知ってる？」→「〜を知ってる？」
- 「〜することができる」→「〜できる」
- 「〜ということ」の多用 → 省略するか言い切る
- 「の」が3連続以上 → 文を分割して解消する
- 口語と書き言葉の混在 → どちらかに統一する
- 「──」「——」（ダッシュ記号）→ 全面禁止。句点・読点・接続詞で置き換える（ルートCLAUDE.mdの禁止ルール。AI臭くなるため）
