## 2. そのまま使えるもの（文体ルール）

既存ブランドで検証済み。新事業でも効くはず。

- 一文は短く、改行多め（縦長レイアウト）
- 難しい言葉を使わない（中学生でも読める）
- ぼかし表現禁止（「〜かもしれません」「〜と思います」）。専門家として断言する
- 文末を「だ。」で終えない。動詞・形容詞で終えるか、「です／ます」を混ぜる
- 「——」「──」のダッシュ記号は使わない
- 詩的・気取った比喩は禁止。あっけらかんと言い切る
- 患者・お客さんのセリフは「」で生々しく（模範解答風にしない）
- 「治る」「治療」は使わない（医療広告の観点。「楽になる」「軽くなる」で言う）
- 絵文字は1投稿3個まで、「！」は2個まで

### 伸びる構成（970件分析の結論）
- **「今日来た〇〇の人が〜」で始まる施術エピソードが最強**。これはマッサージでもそのまま使える
- 数値変化は必ず「施術×数値」のペアで段階的に書く
  - ✅「まず足首をゆるめて、首の重さが10から6に。次にふくらはぎで6から3に」
  - ❌「揉んだら10→6→3になった」（裸の矢印は禁止）
- **意外な因果関係が刺さる**（足首→頭痛、肺→股関節痛）。これは小難しくないので新事業の主力になる
- チェックリスト形式（①②③）は読まれる
- 長さは150〜250字が主役。500字級は1バッチ1本まで

## 4. DM導線の設計（この会話の最大の資産）

無料セッションの予約ページ（他者のもの）を分析して特定した、**申し込み直前に人が引き返す理由**。業種を問わず効く。

### 抵抗が生まれる6つの原因
1. **その先が読めない**：申し込んだ後に何が起きるか書いていない（何をされるか・何分か・売り込まれるのか）
2. **要求が重い**：無料なのに「120分」「顔出し必須」など、客側への要求だけが明確
3. **効果の言葉がぼけている**：「〜していける機会になる」式の三重のぼかし
4. **主語が提供者**：提供者の回復物語が長く、客がどうなるかが薄い
5. **他人が変わった証拠がない**：本人の物語だけで、お客さんの実例がゼロ
6. **対象が広すぎる**：「悩んでいる方どなたでも」では自分の顔が映らない

### 潰し方（既存ブランドで実装済み・新事業にも移植する）
- **「予約のあと何が起きるか」を見せる投稿**を月2〜3本つくり、固定投稿にする
  - 既存版：①返信は私がする ②やり取りで日時を決める ③当日は〜 ＋「時間は約1時間を想定してください」
  - 場所は書かない（遠方の人は最初から自分で言ってくる）※マッサージは来店前提なので**場所は書くべき**。ここは要変更
- **初手のハードルを極限まで下げる**：「最初は『お願いいたします』だけでいい。あとは私が聞く」
  - 合言葉は媒体をまたいで統一する（Threadsとnoteで違う言葉にしない）
- **無料と有料の境界を一行で明示**：既存版は「DMのやり取り自体は無料。有料になるのは遠隔ヒーリングを受けたいと言ってくれたときから」
- **緩和句を数本に1回**：「無理に思い出さなくていい。覚えてる範囲でいい」（マッサージ版では「うまく説明できなくて大丈夫。触れば分かる」等に翻訳）
- **「過去にいただいたDM実例」という言い方はしない**：「自分の相談も公開されるかも」と読まれる。主役は「雛形」にして、実例に触れるときは「本人が分からないように書き直してる」と必ず添える

### note（無料記事）の使い方
- **本文にリンクを貼らない**。Threadsは外部リンクでリーチが落ちる
- 「雛形と相談のやり取りの例を無料noteにまとめてある。プロフィールから読める」と**存在だけ**知らせる。単体の案内投稿は月2〜3回まで
- 案内の順番は必ず**「本線→安全網」**：「最初は〇〇だけでいい（本線）→ 不安な人用に雛形がある（安全網）」。noteを読むことを予約の前提・宿題にしない

## 5. 投稿づくりの運用ルール

- 1バッチ10本なら骨格を割り当て制にする：施術エピソード型2〜3本／列挙・対比型2本／お客さんのセリフ始まり2本／「〜な人へ。＋〜な性格じゃない。」型は3本まで
  - 理由：プロフィールを縦に見た人に量産テンプレと思われないため
- 同じ文形（「〜と覚える」「書き出してくれれば〜」等）はバッチ内で言い換えを回す
- **知識型にも現場の一次情報を最低1つ乗せる**：お客さんのセリフ1行、または「この相談が一番多い」の一言。証拠ゼロの断言だけの知識型は作らない
- 投稿時間は活動時間の9〜23時に分散。早朝5〜9時はゼロ閲覧になる（実測済み）。昼12時・夜18〜23時を厚めに
- 日付は必ず生成日以降にする（過去日で出力しない）

### 伸びない投稿（実測）
- お客さんの顔が見えない一般論・解説の単体投稿（4〜9いいねで停滞）
- 日常つぶやき・業務連絡（「寝よう」「今週パンパン」）
- 同文の再投稿（初回の1/10以下に減衰）
- 数値変化・具体例・CTAのない断片知識
- リンクをCTAにした投稿
- 雑学バズ狙い（閲覧は伸びるが客層が増えない）

## 6. AI臭さを消すチェックリスト

この会話で実際に指摘を受けて修正した点。文章を書いたら必ず確認する。

- [ ] **全セクションが決め台詞オチで終わっていないか**（これが最大のAI臭さ。所々フラットに終わらせる）
- [ ] 「ここからが書いておきたかったことです」式の**自分で盛り上げる前振り**を使っていないか
- [ ] 「〜じゃない。〜だ。」の否定→断定を連発していないか（1本に1回まで）
- [ ] 機械的な三段並列になっていないか
- [ ] 各段落の長さ・リズムが揃いすぎていないか（不揃いにする）
- [ ] 説明を重ねすぎていないか（短く切って次へ）
- [ ] 抽象論で終わっていないか（触った感触・お客さんのセリフ・意外な見立てなど、現場の人しか知らない具体で語る）
- [ ] 本人の自己開示（失敗談・羨ましかった話など）が入っているか。1本に1つ入ると一気に人間になる
