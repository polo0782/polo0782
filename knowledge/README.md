# knowledge/ の使い方

Threads投稿の「ネタ元」をためる場所。
Claudeは投稿を生成するとき、ここを必ず参照する。

## フォルダー構成

| フォルダー | 中身 | 更新タイミング |
|---|---|---|
| `episodes/` | 施術エピソードのメモ（最強のネタ） | 施術があった日にメモ |
| `insights/` | 意外な因果関係・専門知識のストック | 気づいたとき随時 |
| `buzz/` | バズった投稿の分析メモ | 投稿が伸びたとき |

## 運用ルール

1. **エピソードは雑メモでOK**
   `episodes/_TEMPLATE.md` をコピーして、その日のうちに書く。
   患者の言葉はそのまま書く（これが一番刺さる）。
   数値変化（10→6→3など）を必ず残す。

2. **書き方より「事実」を優先**
   文章を整えるのはClaudeの仕事。
   メモは箇条書き・走り書きで十分。

3. **使ったエピソードには印をつける**
   投稿に使ったらファイル冒頭の `使用済み: no` を `yes` に変える。
   同じネタの使い回しを防ぐ。

4. **個人情報は書かない**
   名前・特定できる情報はNG。年代・性別・症状だけにする。

## Claudeへの依頼例

- 「episodes の未使用ネタから投稿を3パターン作って」
- 「insights の◯◯を使って知識型の投稿を作って」
- 「この投稿が伸びたから buzz に分析メモを追加して」
