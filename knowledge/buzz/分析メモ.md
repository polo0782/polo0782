# バズ投稿 分析メモ

伸びた投稿はここに「なぜ伸びたか」を1件ずつ追記する。
元データは `data/buzz_posts.json` にもある。
たまったらCLAUDE.mdの「バズ投稿の共通点」を更新する。

## 記入フォーマット

```
## YYYY-MM-DD 投稿タイトル（仮）
- 数字: いいね / リプ / フォロー増
- フックの型:
- 伸びた理由（仮説）:
- 次に活かすこと:
```

## これまでの分析（2026-05-18時点）
- 「今日来た患者さん」で始まる具体エピソードが最強
- 数値変化（10→6→3、①②③④消失）は必須
- 意外な因果関係（足首→脳血流、肺→股関節）が刺さる
- CTAは予約誘導より「フォロー保存」が機能する

## 2026-06-12 本人アカウント970件の定量分析（伸びない投稿）
- 上位（最大6,272いいね）と下位（中央値9いいね）の差は「エピソードの有無」が決定要因
- 伸びない: 一般論・解説の単体投稿、日常つぶやき、同文再投稿（1/10以下に減衰）、数値・CTAなしの断片知識
- 同じテーマでも「今日来た人」のエピソードに乗せた版は伸びる → 知識は必ずエピソードで包む
- 詳細は postgen/skills/themes.txt 末尾の禁止リスト

## 2026-06-12 数値表記ルール（本人フィードバック）
- 数値変化は「施術×数値」のペアで段階的に書く。「まず首の調整で10→6。次に肺を整えて6→3」
- 裸の「10→6→3」は因果の証明過程が見えないので禁止（バズ原文も必ずペアで書かれている）

## 2026-06-14 不発分析（トラウマ系10本・全部100閲覧）

### 結果
- トラウマ／機能不全家庭テーマの深掘り10本を、26分おきに一括投稿
- 全10本が閲覧100前後で頭打ち（いいね・拡散ほぼなし）

### 原因の切り分け
1. リーチの問題（最重要）：全部が一律100＝配信が頭打ち。10本を1晩に一括投稿してリーチが落ちた可能性が高い。自分の投稿同士が食い合い、アルゴリズムにも連投を抑制された
2. 文字数ミスマッチ：今回は全部355〜497字。本人の伸びた投稿は中央値147字・最大バズ104字。勝ち筋の2.5〜3倍の長さ
3. テーマの重さ・均一さ：全部が重いトラウマ深掘り。最大バズは「肛門7秒で頻尿改善」「コーヒー抜け」「ナイトソックス育ててる(32字)」など短く意外であっけらかんな小ネタ。重い均一バッチは読者も疲れる

### 次からのルール
- 投稿頻度は1日1〜3本まで。10本一括はやらない
- 文字数の基本は100〜200字。500字級の重い深掘りは1バッチ1〜2本まで
- 全部をトラウマ深掘りにしない。意外な健康ネタ・実用Tips・あっけらかんな小ネタを混ぜる
- まずは短い投稿を1日1本、数日続けてリーチが戻るか観察する
