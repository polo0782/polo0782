# 刺さった言葉・概念型（2026-07-19・本人の実投稿から抽出）

生きづらさ・コンプレックスの根っこが、トラウマでも世代間連鎖でも霊障でもなく、**「誰かの何気ない一言・世間の空気が、そのまま個人の世界基準として刺さって残ってるケース」**であることがある。原因4分類フレーム（過去/今・自分/他人・自分一代/世代間連鎖・自分への感情/他人への感情）とは別枠の、新しい原因カテゴリ。

## 元になった本人投稿（2026-07-19）
```
札幌市西区でトラウマを取る仕事をしてますが、案外突き刺さる出来事。

生きづらさを抱えた人の原因探しをしていた。
立位で背中を押して筋力弱化してたら図星という調べ方をする。

①現在のこと？過去のこと？過去で弱化
②自分の内面？誰かの影響？誰かで弱化
③自分が言われた？噂話程度？噂話程度

弱化したものをまとめると、
テレビに出てた推しがテレビで
「高身長って素敵だと思う」とか言ってて
それ聞いて身長コンプを持っちゃった。
的な話。
学校でイケてる側の人が◯◯君カッコいいよねと言ってたらそれが人生ずっと世界基準に感じちゃう的な話。

自分が弱いと他人が正しく感じちゃう。
未婚より既婚みたいに、
未婚の優位性だってあるだろとなりにくい。

未婚は平日休日好きなだけゴルフしても誰からも怒られないんだぞ、と既婚者に言っても悪くないのに。

こういうのは生霊とも念とも違う、
言葉や概念が刺さってるケース。

ゴルフ好きなら消せてるが
消せずに苦しんでる人もいる。
アタイはすぐ除去する、邪魔なら。

不調とは別として案件として存在するから
気になる人はフォローお願いいたします。
```

## 具体例ストック
- 推しがテレビで「高身長って素敵」と言うのを見て、身長コンプレックスを持つようになった
- 学校でイケてる側の生徒が「◯◯君カッコいいよね」と言っていたのが、そのまま人生の世界基準として刷り込まれた
- 未婚/既婚のような、本来どちらにも優位性があるはずの二項対立で、片方だけが「正しい」と刷り込まれる（例：未婚は平日休日好きなだけゴルフしても誰にも怒られない、という優位性は語られにくい）

## 見立てのプロセス（ぐらつきチェック・3軸の質問フロー）
立位で背中を押して筋力弱化（ぐらつき）するかで「図星」を調べる。3つの軸を順に質問しながら絞り込む：
①現在のことか、過去のことか → 過去で弱化
②自分の内面のことか、誰かの影響か → 誰かの影響で弱化
③自分が直接言われたことか、噂話・伝聞程度か → 噂話程度で弱化

→ **原因4分類フレームの4軸に、5つ目の軸候補「直接言われた／伝聞・噂話程度」を追加できる**。伝聞・噂話程度の方が、実は根深く刺さっていることがある、という意外性がこの型の面白さ（本人談で言う「噂話程度で弱化」が一番の発見ポイント）。

## この型の特徴・使い方
- **生霊・念とは違う、という位置付けを明示する**（「こういうのは生霊とも念とも違う、言葉や概念が刺さってるケース」）。スピリチュアル色をつけない新しい原因カテゴリとして使える。霊障3割枠の外にある新しい語り口
- **「自分が弱いと他人が正しく感じちゃう」という認知の歪みの説明が刺さる**。持ってる側の優位性が語られないだけで、実際には対等な二項対立であることが多い（未婚/既婚の例が分かりやすい定番）
- **症状ではなく「案件」として扱う新しい切り口**：不調の有無を問わず「気になる人はフォロー」という間口の広いCTA。深刻な不調を抱えてない人にも刺さる汎用性がある
- **消せている人と消せずに苦しんでいる人がいる、という個人差の言及**（「ゴルフ好きなら消せてるが、消せずに苦しんでる人もいる」）。誰にでも当てはまるが深刻度は人による、という間口の広さと専門性を両立させる説明
- 定型の引き受け宣言：「アタイはすぐ除去する、邪魔なら。」（軽いパンチライン）

## 運用
- こだわり型・知識型・領分宣言型のどれにも展開できる。「案件」として扱う軽さがあるので、重い施術エピソードが続いたバッチの箸休め・間口拡張枠として使うと良さそう
- CTAは「フォロー」寄り（DMより間口が広い。不調の自覚が薄い層も拾える）
