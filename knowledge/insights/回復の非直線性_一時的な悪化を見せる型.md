## なぜ効くか
- うちの既存パターンは「外した→良くなった」の一直線ストーリーがほとんど。実際の回復はそんなに単純じゃないという実感を持ってる読者に、綺麗事に見えて信頼されにくいリスクがある
- 「良くなる過程でしんどくなることもある」と先に言っておくことで、実際にそうなった時に「失敗した」「効いてない」と離脱されるのを防げる（期待値のワクチン接種効果）
- 抑え込んでた感情が外れる時に一度表に出てくる、という現象は実際にある（好転反応に近い）。これを正直に語ることが、逆に専門性と誠実さの証明になる

## 使い方
- 「治る過程は一直線じゃない」「外れる途中で一時的にしんどくなる時期がある」を明示する
- 原因：抑え込んでた感情が、外れる瞬間に一度表に出てくるだけ。後退ではない
- 「ここでやめるのが一番もったいない」「その波も含めて伴走する」で私が引き受ける式に着地させる
- 治療の2段階論（第1段階クリア後に本題が来る）とも接続できる：「本題に入ると、一時的にしんどくなることもある」

## サンプル1：知識型・短文
```
トラウマを外してる途中、一時的にしんどくなる時期がある。

これ、失敗じゃない。

抑え込んでた感情が、
外れる時に一度表に出てくるだけ。

ここで治療をやめると、一番もったいない。

私はこの波、何十人も見てきた。

思い当たる人は、DMをくれ。
```

## サンプル2：施術エピソード型
```
今日来た人、10年もののパニック障害の40代女性。
数回の施術で、発作の頻度はかなり減った。

でも先週、急に「もう一生治らないんじゃないか」と涙が止まらなくなったと連絡が来た。

これ、後退じゃない。
抑え込んでた感情が、外れる時に一度表に出てきただけ。

「そのまま感じきってくれ、また落ち着く」と伝えた。
数日後、「今はまた落ち着いてます」と本人。

良くなる過程は、まっすぐな一本道じゃない。
その波も含めて、私が伴走する。

こういう話が好きな方、フォロー保存お願いいたします。
```

## 運用メモ
- 「治る・治療」不使用ルールは通常どおり。上記サンプルの「治療」は一般名詞としての言及（うちの施術を指す断定ではない文脈）なので許容範囲だが、気になるなら「施術」に置き換え可
