# 固定投稿候補：ゆる募・無料相談

2026-07-11、既存の「ゆる募企画」投稿（応募条件・応募方法・料金と見出しで区切った告知チラシ形式）の反応が悪化したため、拓郎節で書き直した。スレッズ公開OK／非公開1000円の二択は撤廃し、無料相談一本のシンプルな入口に統一。

## 確定版

```
不調やメンタルの悩みがあって、誰に相談していいか分からない人へ。

今の症状と、今までやってみた対策やサプリを、DMで聞かせてくれ。
原因の見立てと、私なりの対策を返す。相談は無料でやってる。

話を聞いて、遠隔施術が合うと判断したら、その時は正直に勧める。
無理にはすすめない。

整形外科的な痛みだけは、一度直接見せてもらわないと分からないから対象外にしてる。
それ以外は大体聞ける。

情報は細かく書いてくれるほど、見立ては当たりやすい。
八方塞がりで、誰かに切り込んでほしい人ほど向いてる。

フォローしてから、DMで「お願いします」とだけ送ってくれ。あとは私が聞く。
```

## 設計判断のメモ
- 旧版が伸びなかった理由：①「応募条件」「応募方法」「料金について」の見出し構成が告知チラシ・アンケート形式になっていて、CLAUDE.mdの発信の大原則（1人に話しかける）に反していた。②スレッズ公開OK(無料)／非公開(1000円)の二択が、DM前から「値踏みされる」不安を生んでいた可能性
- 公開・非公開の分岐と課金の話は丸ごと削除。無料相談だけのシンプルな入口にした
- 「遠隔施術を勧める可能性がある」旨は隠さず先出しする（本人承認・2026-07-11）。後から急に営業された感を出さないための保険。「無理にはすすめない」を必ずセットで添える
- CTAは「フォロー→DM」の順にする（2026-07-11考察）。フォロー直後にDMしてくる人は、フォローなしでDMだけしてくる人より明らかに熱量が高いため。「フォロー必須」と強制条件化はせず、語順の誘導にとどめる
- DMの書き方の細部（雛形）は別noteに任せているので、投稿本文で「書き方が分からなくても〜」と手取り足取り説明する必要はない
- 非フォロワーからのDMは無視・削除している運用だったが、この投稿はリーチ経由の非フォロワーにも刺さるように作っているため、掲載直後〜数日はリクエスト欄も確認した方がいい（それ以外の日は従来通りでよい）
