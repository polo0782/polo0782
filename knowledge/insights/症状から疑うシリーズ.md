# 「この症状はこれ疑う」シリーズ（症状→疑うものの対応集）

2026-08-25作成、同日4回改訂。「夕方の不調は低血糖疑う」のような、症状と疑うべき
原因を対応させる型。**体験的パターン（育ち・トラウマ由来）**と**生理学的パターン
（体の仕組み由来）**の2系統がある。

**【2026-08-25改訂】1投稿1ペア形式に変更**（本人指示：「疑うシリーズは1個ずつ
にしよう。足首が固い→脳血流みたいに」）。列挙型（1投稿に6項目）はやめた。

**【2026-08-25再改訂→本人記入で復活】生理学的パターンは一度、根拠不足で
症状の羅列に降格した**（体験的パターン12本は経験則データベースの⑨⑫が根拠だが、
生理学的パターンはClaudeの推測だった）。その後、症状候補を44個に増量し、
**本人が実臨床の傾向で原因欄を記入**（空欄だった11個は削除、33個が確定）。
これで生理学的パターンも根拠のある対応リストになった。

**体験的パターン12本の投稿本文、生理学的パターン33個の対応リストとも
`postgen/generated/stock_これ疑うシリーズ.txt` が正本。**
生理学的パターンはまだ1投稿1ペアの文章に組んでいない段階（対応リストのみ）。

**使い方**：1バッチ1本まで。個人が特定されないよう、症状も原因も一般化した
書き方に留める（「◯歳の時に◯◯された」のような一意な経歴は書かない）。

## 体験的パターン：対応リスト（症状 → 疑うもの）

- 夕方になると一気にだるくなる → 気を抜けない家で育った可能性
- 実家に帰ると体調を崩す・頭の中で会話が再生される → 親子関係が終わってない
- 人の顔色を過剰にうかがう、自己主張ができない → 自己主張すると家の空気が悪くなった幼少期の経験
- 常に周囲に過剰適応してヘロヘロになる → 親を不機嫌にさせないよう気を張り続けた幼少期
- 稼げるようになると急に体調を崩す・売る前に出せなくなる → 稼ぐ事・目立つ事への無意識のブレーキ
- 良くなってきたのに急に不調が戻る → 良くなる事自体が怖い場合がある（生きづらさが自分の一部になってる）
- 人に頼れない、忙しくても休めない → 頼る事自体を許されなかった育ち
- 特定の家族（多くは母親）にだけ過剰に顔色をうかがう → 評価不安・条件付きの愛情への疑い
- 男性（または特定の相手）と話すと体がこわばる → 対人関係での決定的な出来事、または思春期の刷り込み
- 何をしても楽しくない、笑えなくなった → 燃え尽きる手前のサイン
- 長子・年上のきょうだいだけ様子がおかしい → 期待やきょうだい間の役割固定の重圧
- 進路や交友関係が急に不安定になる時期がある → 過干渉・先回りされて育った反動

## 生理学的パターン：症状→原因→メカニズム（2026-09-06・本人が全項目にメカニズムを記入）

本人が実臨床の傾向で原因欄を埋めた後（2026-08-25）、2026-09-06に全項目へ
「なぜその原因になるのか」のメカニズムを追記した。これで34本すべてが
根拠付きの完成材料になった。1本ずつ、体験的パターンと同じ1投稿1ペア形式に
組んでポスト化していく（1バッチ1本まで）。

※ 3・19・25番目は本人が記入時に別の症状・原因に差し替えた（元の項目は削除）。
※ 18・23番目は原因欄も本人が調整（18は「筋肉量の低下」を追加、23は「消化不良」に一本化）。
※ 14・15・27・33番目は原因に「偏頭痛」を追加。この4本はメカニズムの文章が同一
　（「偏頭痛は肩もみや首の矯正が頭痛を軽くすることがないケース。」）なので、

　差をつけて書く。同文流用ではなく、この1文を核に毎回別の症状文脈から書き起こす
※ 2・11・16・17・20番目も同じメカニズム文（「複数要因」の話）を共有している。
　こちらも同様に、症状ごとに別の書き出しで語り直す

1. 頭がぼーっとして集中力が続かない → 副腎
   メカニズム：会社員として問題ないかもしれないが、放置してて治る日は来ないと思う。
2. 首こりや股関節痛が、何をやっても変わらない → 痛いとこに原因が無い。ウチ来た人だと足首や背中に原因あることが多い
   メカニズム：うちで肩こりやってても足首と内臓と脳みたいな複数要因の事は多い。頑固な症状は複数要因だと思った方がいい。
3. 朝起きられないが学校行って部活してる未成年 → 消化不良
   メカニズム：運動後、体力減ってて消化能力低下してる説。ベタイン塩酸塩を夕食後に飲ませて消化サポートを勧める。自分も中学以降やっていたかった。
4. 甘いものや炭水化物ばかり食べる → タンパク質不足か、消化能力が弱い
   メカニズム：脳はタンパク質不足と糖質不足の判断ができず、タンパク質不足でも砂糖を欲するようにできている。逆に肉や油が苦手なら消化能力が弱いのだなと思う。
5. 朝調子が悪くて昼近くになると復活してくる → 腕か足が就寝中冷えている説
   メカニズム：レギンスでもレッグウォーマーでも装着して露出させないようにしてみて、当たってたら１日で変わる。
6. 夕方に足がむくむ・靴がきつくなる → 運動不足、私でも朝から長距離運転してるとなる
   メカニズム：重力に体の水分が従ってるだけ、筋肉で循環も促さず。
7. 姿勢悪いせいで肩こり腰痛 → 椅子に浅く座ってる可能性が高い
   メカニズム：椅子に深く座ると深呼吸が100できる、5cmくらい前に座って背もたれよしかかって深呼吸すると95くらいしか吸えない時がある。95のままいると酸欠でコリが出ることが多い。私はダイソーの車コーナーでバックレストを買って対策しているが神商品だと思っている。

   メカニズム：胃酸過剰と見られることが多いが、胃酸不足でも同じ症状が出ることが多い。梅干しを食べて胃液分泌促進して胸焼けが減ったなら不足で確定でいい。むしろ胃酸過剰な人は梅干しを食べると胃痛がするから嫌がる。

   メカニズム：ビタミンB6を体内で活性化させるのが苦手な人がいて、その場合活性化済のP5Pを勧める。たまに市販のビタミンB6で充分な人もいる。

## メンタルの原因候補（2026-08-25追加）

生理学的パターンの回答に「メンタル」と書かれた項目（7・10・12番）がそのまま
使えないので、「メンタル」の中身を具体化する候補リスト。経験則データベースの
⑨⑫、`因果関係ストック.md`、`ヒーリング対象候補.md`の分類を元に羅列した。

- 慢性的な緊張・警戒（気を抜けない家で育った、安全な場所が無かった）
- 我慢・抑圧（本音を出せない、言いたい事を飲み込む癖）
- 過剰適応（人に合わせすぎる、境界線が引けない）
- 燃え尽き（頑張りすぎが慢性化。休んでも疲れが抜けない・笑えない）
- 自己評価の低さ（自分に投資できない、頼れない、休めない）
- 特定の出来事に紐づくトラウマ反応（フラッシュバック、特定の人物・年代への反応）
- 上下関係のストレス（職場・家庭内の力関係、言い返せない、下座固定）
- 見捨てられ不安・評価不安（条件付きの愛情、特定の家族にだけ顔色をうかがう）
- 恩着せ・罪悪感（してもらった分を返さなきゃという重さ）
- 稼ぐ・目立つ事への無意識のブレーキ（起業/発信者に多い）
- 良くなる事への恐怖（生きづらさのアイデンティティ化）
- 世代間連鎖（親自身が、子どもの頃に同じパターンを抱えていた）
- 加害者自身のストレス・未熟さ（親やいじめっ子側も、当時何かに追い詰められていた。
  使う時は必ず「だからといって正当化されない」とセットにする）
- 性的・身体的被害の後遺症（対人観・異性観への長期的な影響）
- 家族の死・喪失の未消化（自死・突然死が何年も引きずる起点になっている）
- 生霊・他人の念（他人の悪意や執着を向けられている感覚）
- 前世（今回の人生に何かを持ち越している感覚）
- 憑いてる感覚・霊障（断定せず「推測して、症状の変化で裏取りする」時だけ使う。
  重大な病気の判定には使わない＝CLAUDE.mdの霊障ルールと同じ線）
