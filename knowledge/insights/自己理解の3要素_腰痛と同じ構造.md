# 自己理解の3要素（腰痛と同じ構造・2026-07-27本人談）

## 核の観察（本人談）
> 「腰痛でもメンタルでも自己理解ってめっちゃ大事。腰痛だと姿勢でも運動不足でも足の古傷でもいいよね。メンタルなら何がダメージくらうことか、何あると幸せか、何故ダメージくらいやすい事象があるのか原体験は何かって話。」

**腰痛と全く同じ構造**、というのがこの見立ての肝。腰痛は「姿勢か、運動不足か、足の古傷か」と原因を一点に絞れれば対処できる。メンタルも同じで、以下の3つが分かれば動けるようになる。

## メンタルの自己理解＝3要素
1. **何がダメージになるか**（自分の弱点・トリガーの特定）
2. **何があると幸せか**（回復・充足の条件。①の裏返しではなく独立した情報）
3. **なぜそれがダメージになるのか＝原体験**（①の理由。ここが根っこ）

①だけ分かっても対症療法止まり。③まで辿って初めて外せる。②は回復の設計に要る。

## 現場での実演例
`知識/episodes/2026-07_パートの職場イライラ_店長が本丸.md`が、まさに①の特定作業の実例。ぐらつきチェックで「セクハラ→平気／怒られること→平気／シフトを増やせないかの打診→強い反応」と、何がこの人のダメージになるかを一つずつ総当たりで洗い出した。本人談「何があるとダメージ受けやすいか調べるのは大事。未然に防げ」。

## 使い道
- **腰痛の例えで入る**のが一番伝わりやすい。「腰痛なら姿勢か運動不足か古傷か、原因が分かれば手が打てる。メンタルも同じ」で始めると、体の話から心の話へ抵抗なく渡せる（①自律神経で頭打ちの層と②毒親育ちの層、2つの客層をつなぐ橋渡しにもなる）
- **「自分では③まで辿れない」→だから私が調べる**、の必然性に直結する。発信の大原則の4段構成（名指し→気づけない理由→だから私が要る→私が見る）にそのまま乗る
- 原因4分類フレーム・3本柱の診断フレームと同系統の「診断の統一視点」として使える

## サンプル（2026-07-27作成）
```
腰痛の原因は、姿勢か、運動不足か、足の古傷か。
どれか分かれば、手の打ちようがある。

自分は何にダメージを食らうのか。
何があれば満たされるのか。
そしてなぜ、それがダメージになるのか。

この3つが分かれば、動ける。

ただ、3つ目だけは自分では辿れない。

思い当たる人は、DMをくれ。
```
