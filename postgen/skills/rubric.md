# 100点の基準（2026-07-28定義）

## この基準が最大化するもの
閲覧数でも、いいね数でもない。**次の2セグメントがフォロー or DMすること**だけを見る。

- **A層＝謎の不調**：病院で「異常なし」「自律神経ですね」と言われ続けてる人。原因が分からないのが一番しんどい状態にいる
- **B1層＝生育環境の顕在**：毒親・機能不全家庭と自覚してる人。自覚はあるが体との接続が繋がってない
- **B2層＝生育環境の潜在**：「うちは普通の家でしたよ」と言う人。**ここが最大の未獲得層**。「毒親」「トラウマ」と言った瞬間に自分ごとから外れるので、症状と行動の描写だけで自己診断させる必要がある

---

## 採点表（1本100点）

### ① 名指し精度 ／ 20点
1行目で「これ私だ」と手が止まるか。
- 属性（30代女性・HSP）ではなく、**行動・場面・時間帯**で切る … 8点
- 症状＋場面＋数字/頻度のうち2つ以上が1〜2行目に入ってる … 8点
- その一人にしか当たらない固有性がある（「夕方4時」「実家から帰ると三日」） … 4点

### ② 仕組み ／ 15点
なぜそうなるかを1〜2行で言い切ってあるか。実測で反応を取ったのは全部これが入ってる回。
- 因果が1本の線で書かれてる … 10点
- 抽象論だけ（「過剰適応の人は〜」）で終わってない … 5点
- ※仕組みゼロは**この項目0点＋全体を80点上限**にする

### ③ 今日タダで試せる検証 ／ 20点 ★最重要
実測でリプがついた回は全部これ。保存→実行→報告（コメント/DM）の起点になる。
- 具体的な行動が固有名で書いてある（食前に梅干し1個／目だけで八方向／健診結果の中性脂肪の欄） … 12点
- **判定の閾値が数字で切ってある**（3つ以上／60未満／4つ以上シロ） … 5点
- 空振りの場合の次が書いてある（「変わらなければ原因は別」） … 3点

### ④ セグメント設計 ／ 10点
- どの層向けか1本ごとに定まってる … 5点
- B2層の回で「毒親」「トラウマ」「機能不全家庭」の語を使わずに刺せてる … 5点
- ※B2層の回でこれらの語を使ったら**この項目0点**

### ⑤ 出口 ／ 10点
症状の解説で終わってない。「原因の特定は自分ではできない／私がやる」まで着地してるか。
- 私が主語で引き受けてる（私が外す・私が特定する） … 6点
- 読者の自己努力では届かないと一行で示せてる … 4点
- ※CTAなしの回でも「自分で測れ・自分で試せ」が出口になっていれば満点

### ⑥ CTA設計 ／ 5点
バッチ全体で配分する。1本単位では「意図して選ばれてるか」だけ見る。
- DM回：DMに書く中身が具体的に指定されてる（数字を送れ・番号でいい）＋緩和句 or 「最初は『お願いいたします』だけでいい」
- フォロー回：「こういう話が好きな方フォロー保存お願いいたします」
- なし回：締めの一行が余韻として機能してる

### ⑦ トーン（実文サンプル一致） ／ 20点
`tone_samples.md` のリズムに一致してるか。整えるほど落ちる項目。
- 段落の行数が不揃い（3種類以上の行数が混在） … 4点
- 80〜300字 … 3点
- 文末に「だ。」「〜んだ。」がゼロ … 4点
- AI臭い対句（「〜じゃない。〜だ。」）が1投稿1回以下 … 3点
- **整いすぎてない箇所が1つ以上**（投げやりな短文／脱線の「というか、」／言い切らない締め／唐突な自己開示） … 6点

## 減点
- 数値を裸で書く（施術×数値のペアでない「10→6→3」） … −10
- **指標がその場で確認できない現象になってる** … −15
  - 施術エピソードの指標は、施術中にその場で動かせる身体現象だけにする（首の固さ・痛さ・筋力テスト・眼球の引っかかり・可動域）
  - 寝つくまでの時間、翌朝の目覚め、出勤できたかは**その場で確認できない**ので指標にしない。これらは「後日連絡が来た」として別に書く
  - ❌「まず胃を整える。寝つくまで90分のまま動かない」（施術中に寝つき時間は測れない）
  - ✅「首の固さを指標にして10。胃を整えても10のまま動かない」＋「『昨日はすぐ寝てました』と後日連絡が来た」
- スピ・霊障系ワードが2回以上 … −10
- 「治る」「治療」／ぼかし表現（〜かもしれません） … −10
- 前バッチと同じフック構文の使い回し … −5
- 「！」3個以上／絵文字4個以上 … −5

---

## バッチ全体の合格条件
- 全10本が**95点以上**、平均98以上
- 同じ型・同じフック構文の重複ゼロ
- セグメント配分：A 5本 ／ B1 1〜2本 ／ B2 3本（B2を厚くする。顕在層は既にDMを送る側なので、獲得余地はB2とAにある）
- CTA配分：DM 4本 ／ フォロー 3本 ／ なし 3本
- **10本中8本以上に「今日タダで試せる検証」が乗ってること**（③が実測上いちばん効くため、ここを落としたバッチは全体で不合格）
