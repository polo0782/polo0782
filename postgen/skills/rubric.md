# 100点の基準（2026-07-28定義）

## 前提：この採点表は1本を測るが、申し込みは1本では起きない（2026-08-01追記）
**申し込むのは、刺さる投稿を何度も見た人。** トラウマならトラウマの話を何度も見た時。
だから満点の1本より、**同じ刺さり方を切らさず当て続ける事**が上位に来る。
- 本筋（トラウマ・自律神経・施術エピソード）を1バッチ2〜3本入れる
- 日内は属性を分散、週内は同テーマを反復
- ただし**濃さが前提**。薄い一般論は何回当てても「この人にやってもらいたい」にならない。
  反復して効くのは、鑑別・見立て・他で聞けない具体が入ってる回だけ（②と③が本体）

## この基準が最大化するもの
閲覧数でも、いいね数でもない。**次の2セグメントがフォロー or DMすること**だけを見る。

- **A層＝謎の不調**：病院で「異常なし」「自律神経ですね」と言われ続けてる人。原因が分からないのが一番しんどい状態にいる
- **B1層＝生育環境の顕在**：毒親・機能不全家庭と自覚してる人。自覚はあるが体との接続が繋がってない
- **B2層＝生育環境の潜在**：「うちは普通の家でしたよ」と言う人。**ここが最大の未獲得層**。「毒親」「トラウマ」と言った瞬間に自分ごとから外れるので、症状と行動の描写だけで自己診断させる必要がある

## 採点表（1本100点）

### ① 名指し精度 ／ 20点

**1行目は「浅くて広い悩み」を置く。深くて狭いものを置いた回はマジで伸びない。**

- ❌ 群発頭痛、自己愛性パーソナリティ障害、起立性調節障害、20年ものの鬱
  → 該当者が少ないうえ、当てはまらない人が1行目で降りる
  → ※ **これは「フックとして」の話**。同じ病名を**実績の報告として**出すのはむしろ強い。
    「今日で群発頭痛の人が終了になる」は733閲覧17いいねを出してる（型F参照）。
    狭い病名は、読者を名指す時はNG、こちらの結果を語る時はOK
- ✅ 自律神経やトラウマで八方塞がりな人／何年も体調が戻らない人／
  病院に行っても異常なしで終わる人／どこに行ってもその日だけの人／
  何をしても心が休まらない人／体もメンタルも不安定なのに原因が分からない人

**構造は「広い悩み → 狭い具体」の順**。狭い方（20年もの、夕方4時、中性脂肪60）は
2行目以降に置けば、間口を狭めずに具体を残せる。

- 1行目が浅く広い悩みになってる … 10点
- 2行目以降で具体（症状・場面・数字）に落ちてる … 6点
- 属性（30代女性・HSP）ではなく、行動・場面・状態で切ってる … 4点

#### 1行目に賭け金を置く（2026-08-06追加）
名指しは「誰の話か」。賭け金は「**何がかかってるか**」。別の軸で、両方いる。
名指しだけ完璧でも、失う物が書いてない回は指が止まらない。

- ❌「トラウマが残ってるかどうかは、目で分かる。」… 名指しも賭け金もゼロ
- ✅「25年ものになる前に」… 時間を失う
- ✅「倒れる前に来た方が早い」… 働ける状態を失う
- ✅「稼げるようになると、逆に怖くなる」… 手に入れたい物に触れてる

このアカウントの読者が失いたくない物は、だいたいこの5つ。
　・動ける時間（1日が横になって終わる）
　・子どもとの関係（怒鳴ってしまう）
　・仕事（休職・辞めざるを得ない）
　・年数（放置した分だけ戻りが遅くなる）
　・「自分の性格」だと諦めてる部分（本当は取れる）

※ **美容の賭け金（老ける・太る・肌・髪）は使わない。** 閲覧は伸びるが
　 狙いの女性フォロワーが増えない。肛門・ナイトソックスと同じ罠（970件分析の結論）。
　 賭け金の原理は正しくても、題材を間違えると本筋が薄まる

#### 自分の為には動かない。誰かの為なら動ける（2026-08-17）
本人「自分の為には動かないかどうかだね」。

このアカウントの狙いの層（人の期待に応えすぎる、境界線が引けない、
感謝されながらヘロヘロ）は、**自分の為だけでは動けない。動くのは、
誰か／何かの為だと思えた時。** これが賭け金リストの「子どもとの関係」が
一番強く効く理由でもある。

- 家庭持ち → 家族に迷惑がかかる、が動く理由になる
- 独身・単身 → 「自己責任だから賭け金が軽い」ではなく、
  **代わりに動いてくれる人がいない分、影響が全部自分に返ってくる**、と反転させる
- **個人事業主なら「自分の事業・顧客が止まる」が家族の代わりになる**
  （本人「個人事業主の方が書きやすいわ」＝ 拓郎自身が事業主なので、
  ここは想像ではなく自分の実感で書ける。CLAUDE.md「自己開示には出せる範囲と
  出せない範囲がある」に合致——独身女性の孤独感を代弁するより、
  事業主としての実感を書く方が誠実。**書ける範囲を自分の実感に絞る**、
  という判断そのものが賭け金設計の一部になる）

→ 賭け金を書く時は、家族一択にしない。**家族／事業（顧客・仕事）を並走させて、
　 どちらの読者も自分ごとにできる形**にする。ただし1投稿に両方詰め込むと
　 長さが膨らむので、投稿ごとにどちらか1つを選んで使う

**1行目の形をバッチ内で揃えない**。全部「〜な人へ。」にすると名乗りと同じテンプレ化を
起こす。呼びかけ（〜な人へ）／名指し（〜な人。）／断定（午後は使いものにならない）／
症状列挙（足がつる、まぶたがピクピクする）を混ぜる。

#### 常識をひっくり返す型は、その常識を読者が持ってる時だけ使う（2026-08-01追加）
「実は3つじゃなく4つ」「よく言われる〇〇は間違い」は、
読者が元の常識を知ってる場合にしか驚きにならない。知らない相手には置いていく効果しかない。
- ❌「体の危機反応は3つじゃなく4つあります」… 闘争・逃走・凍りつきを知らない人の方が多い
- ✅「体の危機反応。・闘う ・逃げる ・固まる ・合わせる」… 4つそのまま出す
- ACEや情緒的ネグレクトが効くのは理論を知ってるからではなく、**経験の方を持ってるから**。
  ひっくり返す対象は「読者の実感」であって「学説」ではない

#### 食べる量は3つに分ける（2026-08-01追加）
「少食」と「腹八分」を同じ軸に置かない。混ぜると矛盾してないものを矛盾扱いしてしまう。
- **少食** … 食が細くて足りてない人。ウチに来る人の半分以上。**入れる指導をする側**
- **満腹** … 大半の人はここ。満腹まで食べてる
- **腹八分** … 上限の設定。実行してる人はまずいない。**ほぼ全員に効く指導**
- したがって「腹八分を勧める」と「少食の人が多い」は同時に成立する。
  少食の人は元々その上限の下にいるだけで、減らせという指示にはならない
- 一方で**プチ断食は足りてる側にしか勧めない**。ここだけは分けて書く

#### 場面を出す時は、その層が実際にその行動をしてるか確認する（2026-08-01追加）
判定基準を発明しないのと同じ根。**シチュエーション自体を発明しない。**
- ❌「朝ごはんの後、必ず腹が痛くなる人」… 狙いの層は朝食を食べない
- 迷ったら本人に「この場面、実際に来る人にあるか」を聞く。想像で埋めない

#### 例外：シリーズものは見出しで統一する
連作として出す回は、1行目を悩みではなく**シリーズの見出し**にする方が効く。
プロフィールを縦に見た時に連作だと分かり、次を待つ理由になる。
- ✅「４毒の砂糖」「４毒の牛乳。」「４毒の油。」
- 悩みフックは2行目以降で拾えばいい

### ② 仕組み ／ 15点
なぜそうなるかを1〜2行で言い切ってあるか。実測で反応を取ったのは全部これが入ってる回。
- 因果が1本の線で書かれてる … 10点
- 抽象論だけ（「過剰適応の人は〜」）で終わってない … 5点
- ※仕組みゼロは**この項目0点＋全体を80点上限**にする

#### 施術エピソードでは「当たった話」より「なぜそこに当てたか」を書く
素人に書けないのは結果ではなく**鑑別の過程**。既往から素直に着地させると浅くなる。
- ✅「既往に鉄欠乏があるが、時間帯で見た時に鉄欠乏は話が違う。この場合副腎疲労を疑った」
  （既往をあえて外す＝消去法が見えると専門性が立つ）

#### 内臓チェックの書き方は固定（2026-08-06・再修正。8/1の修正は誤りだった）
検査は**立位で背中を押してグラつくか**で統一する。腕の力・体幹など言い方をバラさない。
普段は押してもグラつかない。**原因の内臓に触れながら押すと、そこだけグラつく＝当たり。**
- ✅「背中を押すとグラつかないが、○○に触れながら押すと、そこだけグラつく」
- ❌「背中を押すとグラつくが、○○に触れながら押すとグラつかない」（8/1に一度これに直したが逆だった）
- 外れた時は「触ってもグラつきが出ない」

「固さが消える」系は別技法（据え置き・混同しない）。**セラピーローカリゼーション**という技法で、
心臓・横隔膜など、触れた瞬間に固さや痛さが消えるパターンに使う。
足首を触りながら首を動かすと痛みが減る、も同じ原理。
上のグラつき検査（当たりを見つける診断）とは別物なので、書き分ける。

#### 鑑別は外し切らない。保留して次の手まで書く
消去法＝きれいに外す事だと思って断定すると、臨床の実際と合わなくなる。
- ❌「場面が電車限定なのも甲状腺なら説明が付かない」（外し切ってる）
- ✅「寛解後で数値も落ち着いてるし、でも血糖値の問題があるので捨てがたい。
   状況をもっと良くするのに甲状腺に使うサプリも考えてもいいかも」
  （保留のまま次の手を示す。これが現場の思考）
- ✅「首の痛さを指標にして10→7。倦怠感はその場で調べられないため」
  （なぜその指標を選んだかを本文で説明する）
- **観察と推測を混ぜない**。チェック項目は観察できる事実だけを並べ、推測には「と推測」を付ける
  - ❌ ①体幹に力が入らない ②ふらつく ③首が固い ④頭に血が行ってない（④だけ推測）
  - ✅ ③左の首が固いため頭に血が行ってないと推測

### ③ 今日タダで試せる検証 ／ 20点 ★最重要
実測でリプがついた回は全部これ。保存→実行→報告（コメント/DM）の起点になる。

**ただし「検証の形をしたもの」を置くのは無価値どころか有害。まず下の成立条件を全部満たすか確認する。1つでも欠けたら検証として置かず、その回は検証なしで作る（−5の偽検証扱いにする）。**

#### 成立条件（全部満たすこと）
1. **今日その場で着手できる** … 用意するものが手元にあるか100円で買える。受診・予約・取り寄せが要るものは不可
2. **結果が即〜数時間で出る** … 数日〜数ヶ月かかるものは検証にならない
   - ❌「フェリチンを50まで上げても戻らないなら別の原因」（数ヶ月かかる）
   - ❌「3日やって変わらなかったら」（無意味に伸ばしてる。3時に食べて夕方効くかは当日分かる）
3. **判定が体感か、目の前の紙・鏡で分かる。記憶の掘り起こしに依存しない**
   - ❌「怒鳴った時に出た言葉、親と同じか思い出してみて」（渦中の本人は覚えてない）
   - ❌「実家に電話した後の30分、何をしてたか思い出してみて」（覚えてないし選択肢がこちらの作り物）
   - ※書き出しはDMの後に私が誘導する工程。投稿で課す宿題にすると、下げるはずのDMの敷居が上がる
4. **本人が物理的に実行できる** … 対象の状態と矛盾する指示を出さない
   - ❌ 中性脂肪60未満の人に「まず食う量から」（食えないから60を切ってる）
5. **外れても損しない** … 断ちもの・食事制限は外れた時に害が出るので検証にしない
   - ❌「甘いものだけはやめて」（外すと何も食べない人が出る）
6. **該当者を切り落とさない** … 閾値は下回る該当者を排除しないか確認する
   - ❌「4つ以上シロだった人、DMをくれ」（2つ3つでも該当する人が弾かれる）
7. **未来の機会に依存させない** … 「今度〜したら見ておいて」は、その機会がいつ来るか分からず、投稿を見た瞬間に何も起きないまま忘れられる
   - ❌「今度誰かと会ったら、翌日の午前に何ができたか見ておいて」（会う→翌日で最短2日先）
   - ✅ すでに起きたことで判定させる（「実家から帰った日、何日で戻ったか」は本人が覚えてる）
   - ※記憶に依存してよいのは、体調・日数など本人に強く残るものだけ。とっさの発言や30分後の行動は覚えていない（条件3）

#### 一発判定を優先する（読者に作業をさせない）
数える・書き出す・思い返すは、成立条件を満たしていても**実行されない**。
条件を1つ言うだけで判定が付く形にできるなら、そちらが上。
- ✅「土日元気になる人はメンタル確定」（条件1つ、作業ゼロ、言い切り）
- ✅「あなたタンパク質摂ってますか？」（問いかけだけ）

**判定基準を自分で発明しない** … 発明したものは −10
本人が実際に臨床で使っている判定だけを書く。それらしい分岐を組み立てても中身が無い。
- ✅ 本人発：クラクションの反応（怒り／罪悪感／恐怖）、「帰っていいよ」で軽くなるか、
  土日元気になる人はメンタル確定、シチューであたるか、筋力テストで人名を挙げる
- ❌ こちらが作った物：腹を触る、今週3日分を思い返す、食事の回数を数える、
  予定がキャンセルになった時の第一声（これは店舗ビジネスとして話題に出さない方の理由もある）
- 判定を1本入れたくなったら、まず本人の実技から探す。無ければ判定なしで出す

**判定は「これからやる行動」より「すでにある経験」で作る**
未来の行動は実行されない。本人が既に持っている経験を1つ照合させる方が、その場で判定が付く。
- ❌「今夜ホットミルクで1回試すだけで分かれます」（今夜まで待つ、忘れる）
- ✅「シチューであたらない人は乳脂肪」（もう食べたことがある。今この瞬間に分かる）
- ✅「ふいにクラクションの音を聞いた時の反応」（全員に経験がある）
- ※記憶に依存してよいのは、体調・日数・強く残る出来事だけ（条件3を参照）

**最上位の形＝誰でも持ってる実体験1つで、多分岐に自己分類でき、判定後の指針まで付く**
```
ふいにクラクションの音を聞いた時の反応が
・うるせーな！だったら怒りでメンタル揺れやすい
・俺か！だったら罪悪感
・こわっ、だったら恐怖

うるせーな！の人は悲しみや恐怖でダメージ受けることは少ない。
代わりに怒りでブレやすいので怒る状況を回避した方がいい。
```
作業ゼロ・想像すら不要・3分岐で当てはまる人が漏れない・分類後にやる事が書いてある。
「腹を触ってみて」のような行動が要る検証より格上。
- ❌「今日の食事で卵・肉・魚・大豆が何回出たか数えてみて」
- ❌「昨日一日で口に入れた物を全部書き出してみて」
- ❌「今週の3日分を思い返してみて」

#### 配点
- 成立条件を全部満たす行動が固有名で書いてある（食前に梅干し1個／行く前に電話で「フェリチンできますか？」／目だけで時計回り） … 15点
- 判定が本人の体感か手元の紙で完結してる／条件1つで一発判定が付く … 5点
- **判定を読者ではなく私が引き受ける形も満点扱い**（「これはDMを見たら判別がつく」）。読者に宿題を出さずに済むぶん、むしろ上位

#### 予言→的中は証拠として最上位
「こうすると、こうなるよ」と先に言い、後日その通りになった報告が来る形。
検証を読者の宿題にせず、施術者の予測精度そのものが証拠になる。
- ✅「1日ならコーラいいですよ、でも2日連続で飲むと下痢するから気を付けて」と伝えた
  → 「2日連続で飲んだらマジで下痢しました」と後日
- 禁止（やめろ）ではなく**許容量と回数で管理**する提案にすると、実行率も上がる

### ④ セグメント設計 ／ 10点
- どの層向けか1本ごとに定まってる … 5点
- B2層の回で「毒親」「トラウマ」「機能不全家庭」の語を使わずに刺せてる … 5点
- ※B2層の回でこれらの語を使ったら**この項目0点**

### ⑤ 出口 ／ 10点
症状の解説で終わってない。「原因の特定は自分ではできない／私がやる」まで着地してるか。
- 私が主語で引き受けてる（私が除去する・私が特定する） … 6点
- 読者の自己努力では届かないと一行で示せてる … 4点
- ※CTAなしの回でも「自分で測れ・自分で試せ」が出口になっていれば満点

### ⑥ CTA設計 ／ 5点
**本数配分で決めない。その回で読者がどこまで到達するかで決める。**

| 読者の到達点 | 選ぶCTA |
|---|---|
| 気づいただけ（自己診断で「これ私だ」まで） | **フォロー**。この段階の人はまだDMを送らない。手前で囲う |
| 手元に物証がある（健診結果の数字・受けた検査の数・チェックの個数） | **DM**。送る中身が既にあるので敷居が低い |
| その場で試せる行動を渡して終わる回 | **なし**。締めの一行を余韻にする |

- DM回：DMに書く中身を指定する（「数だけでいい」「三日です、だけでいい」「最初は『お願いいたします』だけでいい」）
- フォロー回：属性を名指す方が汎用文より精度が高い（「過剰適応の方、フォローお願いいたします」＞「こういう話が好きな方」）
- ❌ 気づきどまりの回でDMに飛ばす（送る材料がないので流れる）
  - 「何を言われたかだけでいい」は物証ではない。共感で終わる回はフォローにする

#### 最上位のCTA：重症度の認識を変えて直接来させる
検証の空振り条項で締めるより、「その状態はもう普通じゃない」と気づかせる方が強い。

#### 要約文を書かない。これがAI臭の本体（2026-08-01・本人指摘）
**抽象名詞を主語にして状態を要約した文**が、一番AIっぽくなる。
- ❌「そこまで来てるのは、**原因**が置きっぱなしになってるだけ」
- ❌「かけてきた**総額**の方がずっと大きい」
- ❌「仕事は続くのに、**体**だけ先に壊れていく」

**判定法：その文、現場を見てない人でも書けるか。** 書けるなら要約なので捨てる。

本人の実文には要約が1つも無い。全部この3つのどれか。
1. **人のセリフ** … 「肩を揉んでも戻るわけだ、と本人が言ってた」
2. **その場の実況** … 「想定より呼吸も変わらん」「毎回びっくりされる」
3. **投げた感想** … 「めっちゃ普通の話。」「たかが1時間なのに。」「何でなんでしょうね。」

書き換えの例
| 要約 | 置き換え |
|---|---|
| 原因が置きっぱなしになってるだけ | 「いつからですか」と聞くと、だいたい5年前とか言う |
| かけてきた総額の方がずっと大きい | いくら使ったか一回足してみてほしい（読者に計算させる操作にもなる） |
| 体だけ先に壊れていく | 「まだ働けてます」と言う。言いながら顔が死んでる |

**特に出やすい癖（見つけたら全部潰す）**
- 「〜なだけ」「〜が増えるだけ」で締める
- 「体だけ先に◯◯ていく」（削れる／壊れる／降りてくる）
- 「〜の方がずっと〜」の比較構文
- 「置きっぱなし」「置いたまま」＋時間の副詞で深みを出す

#### セリフで書く。解釈を渡さない（2026-08-03・全ジャンル横断）

上の「要約文を書かない」の続き。**要約を消すだけでなく、解釈も渡さない。**

判定はこれ。**「この人よく分かってる」で止まるか、「この人わかってくれてる」になるか。**
前者は感心、後者は好き。申し込みに繋がるのは後者だけ。
解釈まで書くと前者で止まる。**読者が意味を自分で埋める余白を残す。**

- ❌ 「これが〜のつらいところ」「〜という構造です」と説明で締める
- ✅ 言われた言葉をそのまま置いて、意味は書かない

**① 追い打ちは褒め言葉か心配の形で来る。ここが一番効く。**

殴られた言葉（役立たず・死んじまえ）は既に扱ってきたが、
**善意の言葉の方が母数が多く、しかも返せないので残る。**
読者が「それ被害だと思ってなかった」と気づく分だけ強い。

| ジャンル | 追い打ちの言葉 |
|---|---|
| 謝罪 | 「優しいね」「もう許してあげなさい」 |
| 働き蟻 | 「助かる」「ほんと頼りになる」 |
| 実家 | 「痩せた？」「ちゃんと食べてるの」 |
| 親子逆転 | 「しっかりしてるね」「お姉ちゃんだから」 |
| 迎合反応 | 「怒らないよね」「話しやすい」 |
| 乳幼児の母 | 「お母さんが元気じゃないと」 |
| 情緒的ネグレクト | 「手のかからない子だった」 |

**② やられた側に喋らせない。**
周りだけが喋る形にすると、**発言権が無い事が説明ぬきで伝わる**。
文章で「発言力が弱い」と書かない。形で見せる。

**③ 地の文は最小限。** 名乗りと引き受けの一行だけ残す。

  「様子見してたら貯金が尽きて治療にお金をかけられなくなる、だから今のうちにやろう」

  失敗する理由は3つ重なっている。
  1. **終着点の予測に戻ってしまう。** 「貯金が減ってるジリ貧」は現在進行形だから効くが
    （rubric「詩的な比喩は本人が使った言葉でも切られる」参照）、そこに
    「だから〜できなくなる」を足した瞬間、また架空の未来地点の予測に戻る。
    生活保護・逸失利益と同じ穴
  2. **論理として滑り台論法（スリッパリー・スロープ）になる。** A→B→C→破滅、の多段連鎖を
    確定した未来として提示すると、賢い読者ほど「そこまで言い切れる根拠は」と距離を置く
  3. **完全に売り手都合の主張になる。** 「今払わないと倒産する」は広告代理店が言うと
    露骨に自社の商品を売る為の脅しに聞こえる。**言ってる本人が一番得する主張は、
    信用が乗らない。**「Bのさらに上」（黙っていられるのに言う情報）の裏返しで、
    **言わなくていい事をわざわざ言うと信用が落ちる**

  → 対策は「今のうちに」を削り、**現在進行形の事実だけを置いて止める**。
    予測・煽りの一文を足さない。効いてるのは常に「今すでに起きてる事」であって
    「このままだと将来こうなる」ではない

### 19｜共感・断定で終わる投稿は、束で読むと読者を沈める（2026-08-19・実体験）

### 20｜説明の尻尾を切る。締めは「意味の解説」ではなく「素っ気ない一言」でいい（2026-08-19）

- ❌「期待値さえ合ってれば、無駄になる事はまず無い。」
  → ✅「第一会ったこともないのに、と心の中で思われてしまうからこの質問自体止めてね。」
  （解説をやめて、少し呆れた軽口に変えた。説明ではなく感情が乗ってる）
- ❌「眠くなるのは悪化じゃなく、動いてる証拠。」→ ✅（丸ごと削除。事実だけで止める）
- ❌「聞きにくい事ほど先に書いておく。」→ ✅「たまに聞かれる事。」
  （メタ的な自己解説をやめて、素っ気ない事実に戻した）

**書けた時点の稿は60点だと思って扱う。** 私が最初に書く物は、たいてい
「良い施術者が書きそうな文」に整っていて、そこが上限になっている
（→「★整えすぎない」）。出す前に必ず自分で穴を開ける。

**穴を開ける順番（この5つを上から当てる。最初に引っかかった所が本当の欠陥）**

0. **本人がくれた場面を、勝手に広げていないか**（2026-08-11・実際にやらかした）
　 到達範囲を広げようとして**題材そのものを捨てる**のが一番多い失敗。
　 例：「DMで対策を返し、課金も勧めた上で『自分で何とかしてみます』と断る人」
　 → 私は「本を読んで自力で書き出した人」に一般化して、場面を丸ごと失った。
　 **本人の言葉に出てくる条件は全部残す。**「課金を勧めた後」まで含めて1つの題材
1. **1行目が、その回の題材と一致しているか**
　 セリフ始まりの可否は**その場面自体がテーマかどうか**で決まる。
　 ・場面がテーマ → セリフを1行目に置く（読者はその場面を見に来る）
　 ・場面は背景 → セリフは中盤へ回し、1行目は**来る前の状態**に置く。
　 　 でないと、その場にいる人にしか当たらない
2. **症状が1つ以上あるか**
　 無いと誰に来てほしいかが決まらない（→「削除された回から出た2点セット」①）
3. **主張の根拠が、測れる物か一次情報か**
　 ここが一番よく落ちる。**他の整体師がコピペで言えるならA＝作り直し。**
　 ❌「自分で何とかできる段階ならとっくに何とかなってる」
　 ✅「書き出しても眼球の反応が消えない」
3.5 **読者が自分の側を一発で判定できるか。その軸を発明していないか**
　 「◯年続いてる人は無理」だと、当てはまるか本人が計算しないと決まらない。
　 かといって**私が判定軸を作るとほぼ外す**（「去年の職場の一件なら自力でいける」は
　 私の発明。本人の実際の線は「胃酸・P5P・鉄亜鉛で動きそうな人までがセルフケアの範囲」）。
　 **軸が思いつかない時は書かずに本人に聞く。** 書いた軸は必ず要確認に上げる
4. **私の動詞に目的語があるか**
　 「下ろす」「除去する」が裸で立っていないか（母親テスト）
5. **私の出番があるか。降りていないか**
6. **読者が持ち帰る一語があるか**（2026-08-13追加）
　 症状の列挙と場面の描写だけで終わっていないか。その語で場面が3つ作れるか
　 （→「★AIに任せきれない2点」①）
7. **セリフを説明で受けていないか**（2026-08-13追加）
　 額面で受け取って善意側に丸めていないか。行間を書き起こしたか（→ 同②）

**やってはいけない直し方**：60点稿の言い回しを磨く。
たいてい欠陥は**素材の選び方**にあるので、文を整えても60点のままになる。
1〜5のどこかが割れていたら、**梃子を1つ入れ替えて書き直す**
（4本目の場合は「主観の断定」→「眼球で示す」の1点差し替えで全部直った）。

**チャットには60点稿の問題点も出す。** 直った物だけ見せると
本人が判断基準を追えない。何を捨てたかが次の指示の材料になる。

## ★AIに任せきれない2点（2026-08-13・本人指摘。細谷功『具体と抽象』＋行間の投稿より）

本人の言葉：**「AIに文章をお願いしきれないのは、具体的すぎるのと、行間読めてない事が大きい」**

上の「整えすぎない」「A/B判定」より一段手前の話。**何を書くかを決める段階の欠陥。**

### ① 具体病 ＝ 場面から書き始めている

本の核：**抽象概念の威力は、多くの具体を1語で束ねる事**。
「片付ける」の一語が、本にも皿にも机にも椅子にも文房具にも飲み物にも効く。
そして「一度抽象の世界が見えた人からは、具体の話は冗長で**同じ話を何度もしている**に見える」。

**本人はもう2つ発明している。私が作れていないだけ。**

| 発明済みの語 | 束ねている具体 |
|---|---|
| **上座／下座** | 職場・実母・夫婦・乳幼児の母。全部これ1組で言える |
| **ガリガリ君／伊勢海老** | 義実家の手土産・LINEの返信・職場の土産・問診メモ |

→ **順番が逆だった。私は場面から書き始めている。**
先に語を立てれば、場面は後からいくらでも湧く
（`stock_満点狙い.txt` に場面の在庫が6つ並んでいるのがその証拠）。

**反復で積み上がるのは語彙だけ。** エピソードは毎回違うので積み上がらない。
CLAUDE.md「同じ刺さり方に何回当てられたか」で申し込みが起きる、と直結する。

#### 書く前のチェック（①の実装）
- **この回で読者が持ち帰る一語は何か。** 決まらないなら書かない
- **その語で場面が3つ以上作れるか。** 1場面しか説明できないなら、まだ具体
- 症状の列挙・場面の描写だけで終わった回は、語がゼロなので記憶に残らない

#### A/B判定と衝突させない（重要）
A/B判定は「抽象的な修飾語を疑え」と言っており、一見逆に見える。別物なので混同しない。

- ❌ **中身の無い形容詞**（閑静・存在感が輝く・根本から・丁寧に）… 具体に**還元できない**。これがA
- ✅ **多くの具体を束ねる概念**（片付ける・上座・ガリガリ君）… 具体を**無限に生む**

**判定式：その語から具体が3つ出てくるか。** 出なければA＝作り直し。出れば抽象概念＝資産。

### ② 行間が読めていない ＝ 額面で受け取って、善意側に丸めている

元ネタは風俗キャストの投稿。「どうしてこの仕事しようと思ったの？」という
表面上は普通の質問を、**行間ごと書き起こしている**。

```
🧑『こんな汚い仕事をしようと思うなんて謎すぎる
　　この俺らより劣った考えに行き着いた事に興味がある
　　こんな頭おかしい仕事しようなんてどういう思考回路してるのか
　　後学の為に是非聞きたい』
```

プロ野球選手への同じ質問とは根本的に違う悪意がある、という指摘。
**同じ言葉でも、誰が誰に言うかで意味が反転する。**

**私の癖：セリフを置いた後、それを説明で受けてしまう。しかも善意側に丸める。**
- ❌「親が不機嫌になりやすい人の処世術」… 説明。行間を書いていない
- ✅ 母のセリフを、悪意ごと書き起こす

#### 型（そのまま使える）
セリフ → **「行間を読むとこうなる」** → 裏の意味を**相手の口調で、長めに** → 判定

```
「怒ってないよ」
行間『怒ってる。でも怒ってると言った瞬間に私が悪者になる。だからあんたが察して先に謝れ』
```
```
「あんたのために我慢したのよ」
行間『私の人生が終わったのはあんたのせい。返済は一生続く。返し終わる日は来ない』
```
```
「しっかりしてるね」
行間『これからも私が困らないようにやってくれ』
```

#### ★行間＝深層意識が受け取って保存した内容
ここが拓郎のメカニズムと直結する。

**親に実際に悪意があったかは問わなくていい。** 除去対象は行間の方。
「意識の奥が当時を危険だと覚えている」の"当時"の中身が、まさに行間。
- だから「親は悪意が無かったかもしれない。でも子にはこう届いた」で書ける
- **B2層（うちは普通の家でした）に効く**。毒親・トラウマの語を使わずに刺せる（④で満点）

#### 既存ルールとの関係
「追い打ちは褒め言葉か心配の形で来る」の表（優しいね／助かる／しっかりしてるね／
手のかからない子だった）は、**行間を読んだ結果の一覧**だった。
表はあったが、それを生む道具の方が言語化されていなかった。行間読みがその道具。

#### やりすぎの線
- 全部を悪意で解釈しない。**行間として提示する**（「行間を読むとこうなる」）。
  「親はこう思っている」と断定すると決めつけになる
- 見立ての断定はしてよい（それが仕事）。断定するのは**子に何が残ったか**の側

## 長さは「その回で読者に渡す判断の数」で決まる（2026-08-11・本人「いつも無駄に長いから」）

本人が私の250字の回を175字に削った。消えたのは締めの3行
（「私の言葉で安心できるなら苦労してません／数字で見てきてくれ／
異常なしが出てからが私の担当です」）。

**私は毎回「症状＋根拠＋工程＋引き受け＋CTA」を全部載せようとして伸びている。**
実績値は 181字・169字・128字。あの長さは削った結果ではなく、
**渡してる判断が1つしかないから短い**。

・**判断1つの回 … 150〜190字**（例：先に病院行け。以上）
・工程の線引きや根拠の提示が要る回 … 200〜250字
・250字を超えたら、**判断が2つ入っていないか疑う**。たいてい足しすぎ

**引き受けの一行は全ジャンル必須ではない。**
「私の出番が無い回を作らない」は**上下関係ジャンルの合格条件**であって、
断るジャンルの上位条件は「損する側に立つ」。
断ってる最中に引き受けを足すと、自分の営業に戻ってしまって条件が濁る。
CLAUDE.md「CTAは『次の一手』の一形態であって必須ではない」と同じ話。

**書き終えたら、最後の1〜3行を消してみる。** 意味が減らなければそれは足した分。
