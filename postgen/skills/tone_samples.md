**★サンプル5「気遣いレベル指数」と読み比べる。同じ点数ネタで、何が変わったか。**

| | 5（6いいね） | 9（この回） |
|---|---|---|
| 点数の使い方 | **人を採点する**（普通65／親の顔色80） | **場面ごとに必要な点数が違う** |
| 自分 | 出てこない | **自分の点数を晒す**（私はガリガリ君） |
| 例外 | 無し（全部「90は体を壊す」） | **満点で当然の局面を先に認める**（義実家） |
| 締め | ラベル貼り（「あなたは過剰適応」）＋DM | **判定不能という定義**。CTA無し |
| 語彙 | 数字だけ | **ガリガリ君／伊勢海老**が残る |

→ **他人を採点すると説明になる。自分を晒すと実演になる。**
　 5は「あなたは90を出してる」と言われる側に読者を置いた。9は拓郎が先に脱いでる。

**注目点**
- 1行目9字（「不安強い人ほぼコレ」）。極端に短く切って、2行目の名乗り融合で全部言う
- **満点を狙って当然の局面を先に認める**から、次の指摘が説教にならない
- 括弧に本音と裏取りを落として本線を短く保つ（「旦那側は50点でも構わないのに」
  「これ本人に伝えて同意を取っている、向こうも車のローンに回してる」）
- **相手の同意まで書く**のが一番真似しにくい。ケチな話が「合意済みの関係」に変わる
- 具体物2つの対比で**語彙を資産にする**。以後この2語だけで同じ話が何回でもできる
- 一人称が「私」と「アタイ」で揺れている。**揃えない**
- CTAも引き受けも無い。構造の指摘と定義だけで切っている
- ※ 40点・95点は**症状の数値化ではなく、場面に必要な労力の点数**。
